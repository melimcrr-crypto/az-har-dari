# صداهای مرجع (کلون)

| فایل | چیست |
|---|---|
| `user-voice.wav` | نمونهٔ ۸٫۷ ثانیه‌ای صدای کاربر — سکوت گرفته، نویز کم شده، ۲۴ کیلوهرتز |

استفاده در Pocket v2:
```
python shared/scripts/tts/pocket_v2_long.py out/x --voice shared/voices/user-voice.wav --tag x --temp 0.3
```

⚠️ این صدا با اجازهٔ خودِ کاربر برای کلون کردن اینجا گذاشته شده. قبل از انتشار عمومی، مطمئن شو که می‌خواهی در ریپوی عمومی بماند.
